Katz UI

Componentes de interfaz para juegos de mesa. HTML y CSS, cero dependencias, cero build. Salieron de un juego real y están acá para que los uses en el tuyo.

Esta página es la librería: mirá el código fuente, copiá el bloque que quieras del <style> junto con la sección BASE, y listo.

Botones

El truco no es la sombra, es el canto: un box-shadow sólido debajo hace de grosor. Al apretarlo el botón baja exactamente lo que el canto se acorta. Cambiá de estado redefiniendo seis variables — no hay reglas duplicadas.

Dado 3D

Sin librerías: seis caras con translateZ y un cubo que gira. Tocá el dado para tirarlo. Las vueltas se suman al ángulo para que sacar dos veces el mismo número igual se vea como una tirada.

Cartas en abanico

Cada carta lleva su índice en --i y de ahí salen ángulo, altura y solape. Agregar o sacar cartas no toca una línea de CSS. En pantallas chicas el abanico se cierra: las cartas se montan entre sí en vez de salirse.

Fichas de jugador

Las muescas del canto son un repeating-conic-gradient, no doce elementos. Usan los mismos --p1..--p4 que identifican al jugador en toda la interfaz: un solo código de color para un solo dato.

Casillas y tablero

Placas de madera atornilladas. Un tipo de casilla nuevo son cuatro variables y el degradado, el marco y el filete lo siguen solos. Las ranuras de los tornillos van giradas distinto en cada esquina: apretados a mano, no estampados.

Marco de bombillas

Un repeating-linear-gradient por lado, no cuarenta elementos — por eso escala a cualquier tamaño sin que nadie recalcule cuántas bombillas entran.

Cualquier cosa adentro queda enmarcada.

Modal con pestañas

Las pestañas muestran progreso, no sólo secciones: una por la que ya pasaste se ve distinta de una a la que no llegaste. En pantallas angostas queda sólo el número — "1 EL JUEG" se lee peor que "1", y el aria-label conserva el nombre completo.

Formulario

Se abre progresivamente: primero sólo las estrellas, el resto aparece al puntuar. Seis campos de golpe ahuyentan; una pregunta de un clic, no — y quien ya dio ese clic sigue. Las estrellas son CSS puro (el marcado va en orden inverso para que ~ pinte las anteriores).

Tarjetas de personaje

Placeholders: el arte del juego original no viaja. Reemplazá .k-personaje__arte por tu <img> y no hay que tocar nada más. Ojo con el tope del clamp — mirá el comentario en el CSS, es el error más fácil de cometer con esta base.

Barra de tiempo con semáforo

Oro → naranja → rojo, con cortes a los 5s y 2s restantes de 8. Dos animaciones sobre el mismo elemento: una vacía, la otra colorea. Con prefers-reduced-motion se va el vaciado pero queda el color — tres saltos de color no son movimiento, y son la única pista de cuánto falta.
